Mémo Git — commandes essentielles

Voici toutes les commandes essentielles sur Git Bash (Cette page va évoluer avec le temps)

⚙️

Configuration initiale

git config --global user.name "Nom"
Définir ton nom d'utilisateur Git
git config --global user.email "email"
Définir ton email Git
git config --global init.defaultBranch main
Mettre "main" comme branche par défaut pour tous les futurs dépôts
git config --global core.autocrlf true
Supprimer les warnings LF/CRLF sur Windows
git config --global --add safe.directory 'chemin'
Autoriser un dossier sur clé USB ou réseau
🔗

Créer et connecter un dépôt

git init
Initialiser un nouveau dépôt Git dans le dossier courant
git clone https://...
Télécharger un dépôt existant sur ton PC
git remote add origin https://...
Connecter le dossier local à un dépôt distant (GitHub, Codeberg...)
✅

Enregistrer et envoyer

git status
Voir l'état des fichiers (modifiés, non suivis...)
git add .
Ajouter tous les fichiers au prochain commit
git add fichier.py
Ajouter un fichier spécifique au prochain commit
git commit -m "message"
Sauvegarder les changements avec un message descriptif
git push
Envoyer les commits sur GitHub / Codeberg
git push -u origin main
Premier push : envoyer et lier la branche locale au dépôt distant
📁

Fichiers et dossiers

ls
Lister les fichiers du dossier courant
cd "chemin/dossier"
Se déplacer dans un dossier
mkdir "nom du dossier"
Créer un nouveau dossier
mkdir -p "dossier/sous-dossier"
Créer plusieurs dossiers imbriqués en une seule commande
mv "fichier" "destination/"
Déplacer ou renommer un fichier
rm -r "dossier"
Supprimer un dossier et tout son contenu
🗑️

Supprimer des fichiers du dépôt

git rm "fichier"
Supprimer un fichier du suivi Git et du dossier
git ls-files dossier/
Lister les fichiers suivis par Git dans un dossier
git ls-files | grep '~' | xargs git rm
Supprimer automatiquement tous les fichiers temporaires Excel (~$)
echo "~$*" >> .gitignore
Ignorer définitivement les fichiers temporaires Excel
🕐

Branches et historique

git branch -M main
Renommer la branche courante en "main"
git log
Afficher l'historique complet des commits
git log --oneline
Historique condensé, une ligne par commit
git log --oneline --graph
Historique avec un schéma visuel des branches

🔄 Workflow classique — à répéter à chaque modification

git add . → git commit -m "..." → git push
