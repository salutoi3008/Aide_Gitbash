Mémo Git — commandes essentielles

Voici toutes les commandes essentielles sur Git Bash (Cette page va évoluer au fur du temps)

⚙️

Configuration initiale

git config --global user.name "Nom"
Définir ton nom d'utilisateur Git
git config --global user.email "email"
Définir ton email Git
git config --global init.defaultBranch main
Mettre "main" comme branche par défaut pour tous les futurs dépôts
git config --global core.autocrlf true
Supprimer les warnings LF/CRLF sur Windows
git config --global --add safe.directory 'chemin'
Autoriser un dossier sur clé USB ou réseau
🔗

Créer et connecter un dépôt

git init
Initialiser un nouveau dépôt Git dans le dossier courant
git clone https://...
Télécharger un dépôt existant sur ton PC
git remote add origin https://...
Connecter le dossier local à un dépôt distant (GitHub, Codeberg...)
✅

Enregistrer et envoyer

git add .
Ajouter tous les fichiers au prochain commit
git add fichier.py
Ajouter un fichier spécifique au prochain commit
git commit -m "message"
Sauvegarder les changements avec un message descriptif
git commit -am "message"
Commit plus rapidement sans passer par git add
git push
Envoyer les commits sur GitHub / Codeberg
git push -u origin main
Premier push : envoyer et lier la branche locale au dépôt distant
📁

Fichiers et dossiers

ls
Lister les fichiers du dossier courant
cd "chemin/dossier"
Se déplacer dans un dossier
mkdir "nom du dossier"
Créer un nouveau dossier
mkdir -p "dossier/sous-dossier"
Créer plusieurs dossiers imbriqués en une seule commande
mv "fichier" "destination/"
Déplacer ou renommer un fichier
rm -r "dossier"
Supprimer un dossier et tout son contenu
🗑️

Supprimer des fichiers du dépôt

git rm "fichier"
Supprimer un fichier du suivi Git et du dossier
git ls-files dossier/
Lister les fichiers suivis par Git dans un dossier
git ls-files | grep '~' | xargs git rm
Supprimer automatiquement tous les fichiers temporaires Excel (~$)
echo "~$*" >> .gitignore
Ignorer définitivement les fichiers temporaires Excel
🕐

Branches et historique

git branch -M main
Renommer la branche courante en "main"
git log
Afficher l'historique complet des commits
git log --oneline
Historique condensé, une ligne par commit
git log --oneline --graph
Historique avec un schéma visuel des branches
⬇️

Récupérer les mises à jour

git pull
Récupérer et fusionner les dernières modifications depuis le dépôt distant
git fetch
Récupérer les modifications distantes sans les fusionner (pour vérifier avant)
git pull origin main
Récupérer explicitement depuis la branche "main" du dépôt distant
📦

Mettre de côté des changements

git stash
Mettre temporairement de côté les modifications en cours (sans commit)
git stash pop
Récupérer les modifications mises de côté et les réappliquer
git stash list
Afficher la liste de tous les stash enregistrés
git stash drop
Supprimer définitivement le dernier stash sans le réappliquer
🔍

Voir les différences

git status
Voir l'état des fichiers (modifiés, non suivis...)
git diff
Voir les modifications non encore ajoutées avec git add
git diff --staged
Voir les modifications déjà ajoutées (prêtes pour le commit)
git diff main..branche
Comparer deux branches entre elles
🌿

Changer de branche

git branch
Lister toutes les branches locales (la branche active est marquée *)
git switch nom-branche
Passer sur une branche existante (commande recommandée)
git switch -c nouvelle-branche
Créer une nouvelle branche et basculer dessus directement
git checkout nom-branche
Ancienne façon de changer de branche (toujours fonctionnelle)
git merge nom-branche
Fusionner une branche dans la branche courante
⚠️

Erreurs fréquentes et solutions

error: failed to push some refs to '...'
Le dépôt distant a des commits que tu n'as pas en local.
Solution : git pull puis git push
Please tell me who you are (user.email / user.name)
Git ne connaît pas ton identité, la configuration n'a pas été faite.
Solution : git config --global user.name "Nom" et git config --global user.email "email"
fatal: not a git repository
Tu n'es pas dans un dossier initialisé avec Git.
Solution : Vérifie ton dossier avec ls, puis fais git init ou cd dans le bon dossier.
CONFLICT (content): Merge conflict in fichier.txt
Deux personnes ont modifié la même ligne dans un fichier.
Solution : Ouvre le fichier, supprime les balises <<<<<<< et >>>>>>>, corrige le contenu, puis git add . et git commit.
fatal: 'origin' does not appear to be a git repository
Le dépôt distant "origin" n'est pas encore configuré.
Solution : git remote add origin https://...
nothing to commit, working tree clean
Aucun fichier modifié détecté — ce n'est pas vraiment une erreur !
Info : Vérifie que tu as bien sauvegardé tes fichiers dans ton éditeur avant de faire git add .

🔄 Workflow classique — à répéter à chaque modification

git add . → git commit -m "..." → git push
